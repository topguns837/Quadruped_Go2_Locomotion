# Trained models

Curated, intentionally-committed training runs — distinct from `logs/rsl_rl/` (gitignored, every run,
every intermediate checkpoint, local-only). A run only lands here once it's worth keeping around
permanently: a baseline, a milestone in a reward-engineering experiment, something referenced in a writeup.

## Layout

Each run gets its own directory, named `<date>_<short description>` (e.g.
`9_10_26_gait_motion_reward_wrong_arm_mounting`). Inside:

```
<run_name>/
  SUMMARY.md              # curated, human-readable: what this run is, what's different vs. baseline, caveats
  model_<N>.pt             # final checkpoint only (highest iteration) -- see below
  exported/
    policy.pt               # JIT-exported policy
    policy.onnx              # ONNX-exported policy
  params/
    agent.yaml               # full PPO/runner config dump (auto-generated by Isaac Lab)
    env.yaml                  # full environment config dump (auto-generated by Isaac Lab)
```

## What belongs here, and what doesn't

- **Only the run's final checkpoint** (`model_<N>.pt`, highest iteration number) is committed —
  intermediate checkpoints (saved every `save_interval` iterations by RSL-RL) are for resuming an
  in-progress run, not useful once training is done, and would make each run ~15-20x larger in git history
  for no lasting benefit. `.gitignore` technically allows any `models/**/*.pt` through (there's no reliable
  way to gitignore "everything except the highest-numbered file" by filename alone) — leaving out the
  intermediates is a staging discipline: only `git add` the final one.
- **`step_diagnostics.log`** (per-step diagnostic logging, see `mdp/diagnostics.py`) is never committed —
  it's debug output, not a model artifact, and can be hundreds of MB. Already excluded by `.gitignore`
  (`**/*.log*`), no special-casing needed.
- **`SUMMARY.md`** is written by hand for each run — see any existing run's `SUMMARY.md` for the expected
  level of detail. It should be skimmable in under a minute; `params/agent.yaml`/`params/env.yaml` are the
  full source of truth for anyone who needs every last config value.

## Storage note

Plain git, no LFS, as of this writing — fine at the current scale (a handful of runs, tens of MB total).
If this becomes a frequent practice with many runs, revisit: repo `.git` history grows permanently with
every binary committed here, and clone times will grow with it.
